# TIYERI IA V2

Plateforme Web dotée d’une Intelligence Artificielle pour accompagner les agriculteurs.

## Fonctionnalités
- Chatbot agricole intelligent
- Reconnaissance des carences (en cours)
- Interface simple HTML/JS
- Backend avec FastAPI
- Prêt à évoluer vers React

## Lancement
1. Créer la base de données avec `schema.sql`
2. Modifier `.env` si besoin
3. Exécuter `start_tiyeri.bat` sous Windows
